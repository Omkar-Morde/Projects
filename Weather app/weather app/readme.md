# Weather App

A simple weather application built using **HTML, CSS, and JavaScript** that fetches real-time weather data from OpenWeatherMap API.

---

## 🌟 Features
- Fetches weather details for any city.
- Displays temperature, weather condition, and city name.
- Simple and responsive UI.

---

## 🛠️ Technologies Used
- **HTML** – Structure of the app
- **CSS** – Styling for the UI
- **JavaScript** – Fetch API to get weather data
- **OpenWeatherMap API** – Source of weather data

---

## 📂 Project Structure
```
/weather-app
│── index.html      # Main HTML file
│── styles.css      # CSS file for styling
│── script.js       # JavaScript file for logic
```

---

## 🔧 Setup & Usage

### 1️⃣ Get an API Key
- Sign up at [OpenWeatherMap](https://home.openweathermap.org/users/sign_up).
- Get your **API key** from the API Keys section.

### 2️⃣ Clone the Repository
```
git clone https://github.com/your-username/weather-app.git
cd weather-app
```

### 3️⃣ Add API Key
- Open `app.js` and **replace** `your_api_key_here` with your actual API key.
```
const API_KEY = "your_api_key_here";
```

### 4️⃣ Open in Browser
Simply open `index.html` in a browser.

---

## 🎯 How It Works
1. Enter a city name in the input field.
2. Click the "Search" button.
3. The app fetches weather data from OpenWeatherMap API.
4. Displays the temperature and weather description.
